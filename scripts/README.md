# tianmu/scripts

## `corpus_loader.py` —— 共用語料載入器（2026-11-18 建立）

**先跑一次自我對帳**：

```bash
python scripts/corpus_loader.py
```

它會把每個角色的實測漢字數與 `REGISTERED` 的登錄值並列，不符就報出來。

**在量詞頻的腳本裡這樣用**：

```python
import sys; sys.path.insert(0, "scripts")
from corpus_loader import load, load_all, han

tan = load("tan-chuduan")          # 只有原典正文，本庫自己的字已剝掉
for aid, text in load_all().items():
    ...
```

### 為什麼不要再用手找邊界

語料 .md 同時裝著三種文字：本庫的研究評註與檔首 `>` 註記、本庫加的 `###` 分節標題、
以及真正的原典正文。**手找邊界錯過兩次**：

| 日期 | 錯誤 |
|---|---|
| 2026-11-04 | 「女功 33 次」是在**本庫自己的註解**上數的（原典只有 4 次，且全在課表課名裡） |
| 2026-11-17 | 載入器把**本庫寫在檔首的 `>` 註記**算進四份語料的分母（譚處端 +116／劉處玄 +99／王處一 +58／郝大通 +122 漢字） |

所以正文邊界現在寫在語料檔裡，而且**標記自帶預期字數**：

```
<!-- NUWA-CORPUS BEGIN id=tan-chuduan layer=L1 expect=14711 -->
…原典正文…
<!-- NUWA-CORPUS END id=tan-chuduan -->
```

**邊界一漂移，`expect` 就對不上，載入器會 exit 1。**
⚠️ **對不上的時候要查分層，不要改 `expect`。**

### `keep_quoted=1` 只給孫不二

她的**原詩本身是用 `>` 引的**，所以一個會丟掉 `>` 行的載入器會把她的語料刪光。
其餘各檔的 `>` 行都是本庫自述，必須剝掉。
**→ 這個開關必須逐檔設，不能全域。**

## `style_control.py` —— 跨文本比詞頻之前先跑這個（2026-11-18 建立）

```bash
python scripts/style_control.py        # 跑內建的三家《老子》註示例
```

```python
import sys; sys.path.insert(0, "scripts")
from style_control import report
report([("甲", a), ("乙", b), ("丙", c)], words=["治身", "無", "有", "心"])
```

### 它在防什麼

本庫跨文本比詞頻一直用「**每萬漢字**」當分母。那在文體相近的文本之間沒問題，
**但文體一變就有系統性偏差**——**虛詞占比高的文本，每個實詞的密度會被機械地壓低。**

**實例（三家《老子》註，2026-11-18 實測）**：

| | 虛詞占比 | 「無」每萬總字 | 「無」每萬實詞 |
|---|--:|--:|--:|
| 河上公 | 24.3% | 157.3 | **207.7** |
| 李道純 | **19.8%** | 255.3 | **318.2** |
| 王弼 | **35.3%** | 257.7 | **398.4** |

虛詞占比**極差比 1.787**。用總字分母時王弼 257.7 與李道純 255.3 看起來一樣（p=0.908），
本庫因此寫了「兩人同在高無那一側」；**換實詞分母後三對全部顯著（王李 p=0.003），
正確的是三階梯度：河上公 ＜ 李道純 ＜ 王弼**。那條錯誤的敘述已在三個角色檔更正。

### 它輸出什麼

1. **三種分母並列**（總字數／虛詞／實詞）＋ **虛詞占比極差比**。
   **> 1.2 就不要用每萬總字下跨文本結論。**
2. **實測的不變量**——對每個候選詞做**所有成對 Fisher 檢定**，
   **Bonferroni 校正後全部不顯著、且三家次數皆 ≥ 20** 才列出。
   三家《老子》註的結果：**有（極差比 1.02）・若（1.12）・自（1.29）・此（1.63）**。
   ⭐ **「有」是在兩種分母下都齊平的那一個，那是「也」的替代對照組。**
3. 指定詞的**兩種分母並列 ＋ 實詞分母下的成對檢定**。

### ⚠️ 三條使用規矩

1. **不要假設某個字是中性的。** 本庫 2026-11-10 用「也」當對照組（河上公 vs 王弼 p=0.49），
   **兩家時成立，加入第三家李道純就破了**（也／萬總字：506.0／525.6／**140.5**——他是禪門白話體）。
2. **低次數的「不顯著」是檢定力不足，不是齊平。** 故本工具設 **次數門檻 20**
   （若無此門檻，三家《老子》註的「哉」2／3／8 次也會被判為合格）。
3. **用某個詞當對照組時，不能同時拿它下結論**——那會循環。

### ⚠️ 換領域時要重審的一張表

`XU`（純語法虛詞集）刻意**不含** `無 有 為 能 可 得 言 謂 自 相 復`——
**那些在《老子》註一類的文本裡帶內容，放進分母會把要測的東西一起扣掉。**
換到別的文本類型（詩、語錄、醫書）時這張表要重新審。
