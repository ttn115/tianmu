# 《仙樂集》底本題署（zh.wikisource 主頁，非劉處玄正文）

> 取自 zh.wikisource《仙樂集》主頁（2026-11-18 覆核）。
> ⚠️ 本庫 2026-11-17 初建語料時把主頁整頁當成「目錄」排除，**因而漏掉了這行自署**；
> 而當時寫在 `01-` 檔首的註記又把「應緣」誤作「應緳」。此檔即為訂正。

主頁正文行（逐字）：

```
仙樂集
作者：劉處玄　金朝
本作品收錄於《正統道藏》
神山無為應緣長生子劉處玄造
```

## ⭐⭐ 這行自署的兩個詞都在他自己的正文裡復現

**「神山無為應緣長生子劉處玄造」**

| 詞 | 在他 22,116 漢字正文裡 |
|---|---|
| **神山** | **0 次**（全集僅見於此題署） |
| **無為** | 22 次；而**「無為應為」4 次**（「無為應為，誘人開悟」「道離空色，無為應為」「無修有修，無為應為」） |
| **應緣** | **3 次**（「應緣無掛礙，功了行無虧」2 次、「忘世應緣平」） |
| **長生子** | 0 次（他正文不自稱） |

⭐ **所以「無為應緣」不是編者加的頭銜，是他自己反覆說的那四個字。**
⚠️ **而「神山」在他全集 0 次**——此號的來歷本庫未查。
