# 張伯端（紫陽真人）— 人生時間線

## 重要說明：史料層層附會的「箭垛式人物」

與扁鵲、希波克拉底類似，張伯端的生平記載歷經後世層層附會與神化，學者羅爭鳴稱其為「箭垛式人物」——生卒年、籍貫、師承、獲罪原因等關鍵細節，學界至今仍有分歧或存疑。本時間線並列各種說法，不作武斷取捨。

---

## 時間線

| 時間（約） | 事件 | 意義 |
|------|------|------|
| **983/984/987年**（生年三說並存）| 生於北宋天台（一說臨海）| 籍貫爭議本身可能反映「宗教文化地理」現象，而非實際籍貫問題（羅爭鳴觀點）|
| 少年至青年 | 「少業進士」，博覽三教經書，涉獵刑法、書算、醫術、戰陣、天文地理、吉凶死生之術 | 奠定日後融會三教語彙的知識基礎 |
| 青壯年至中年 | 長期任府吏（一說數十年）| 終身未出家，選擇世俗身份中修行 |
| 中年某時 | 因罪被貶謫、編配嶺南兵籍（原因眾說紛紜，多有後世附會神化痕跡；白玉蟾贊詞「元豐一皂吏，三番遭配隸」暗示可能不止一次獲罪充軍）| 人生的關鍵斷裂點，促成後續修道歷程 |
| **1069年**（熙寧二年）| 隨「龍圖陸公」（陸詵）入成都，自述「遂感真人授金丹藥物、火候之訣」（授業之師身分自序未指名道姓，後世附會為劉海蟾，此說學者已撰文質疑）| 內丹傳授的關鍵契機 |
| **1075年**（熙寧八年）| 《悟真篇》成書——律詩十六首、絕句六十四首、五言一首、《西江月》詞十二首（南宋方回質疑此十二首可能是後人夏元鼎增補偽托）| 內丹理論系統化的里程碑之作問世 |
| **1078年**（元豐改元）| 傳因洩露天機遭雷擊警示，發誓不再輕傳《悟真篇》口訣 | 對知識傳授邊界的自我約束（此類記載本身也帶有神化色彩）|
| 晚年 | 於《悟真篇》後增附「歌頌詩曲雜言」三十二首，以禪宗性宗思想補全「性功」部分 | 誠實承認命功系統無法獨自解決心性了悟的問題 |
| **1082年**（元豐五年三月十五日）| 於天台（今臨海）沐浴趺坐而化，《歷世真仙體道通鑑》稱「住世九十九歲」（此享年記載與生年推算彼此矛盾，尚無定論）| — |
| 身後（南宋）| 石泰 → 薛道光 → 陳楠 → 白玉蟾，南宗五祖傳承逐漸成形（實際教團組織者是白玉蟾）| 張伯端本人未建立宗派，南宗作為有組織道派是後世追認建構的結果 |
| 元代以後 | 南宗金丹派逐漸依附、匯入全真道，形成「五祖七真」共尊格局 | 南北宗理論分野（先命後性 vs 先性後命）長期並存 |
| **清雍正年間** | 《悟真篇》被收入禪宗《御選語錄》，敕封「大慈圓通禪仙紫陽真人」| 道教人物被納入禪宗官方語錄體系的罕見案例 |

## 三個關鍵轉折點

### 轉折一：謫戍嶺南——從仕途中人到修道者的斷裂點

中年因罪被貶謫嶺南兵籍，具體原因已不可考（民間傳說版本彼此矛盾，多為後世附會）。**意義**：這場人生斷裂，把一位精熟三教經書、諸種方術的府吏，推向了尋道問道的道路——如同許多重大知識突破的起點，往往不是精心設計的人生規劃，而是變故逼出的轉向。

### 轉折二：成都遇真人傳道——從博學者到內丹傳人的關鍵契機

1069年於成都獲授「金丹藥物、火候之訣」，但自序刻意不指名授業之師。**意義**：這個選擇顯示他一貫重視「內容的真確」勝過「傳承的權威包裝」——同時也為後世附會留下了空間，成為理解「歷史張伯端」與「傳說張伯端」兩層敘事的關鍵分界點。

### 轉折三：《悟真篇》成書——把個人領悟轉化為可被檢驗、可被傳承的文本

1075年，張伯端把自己對內丹修煉的理解系統整理為《悟真篇》，並在晚年進一步增補禪宗性宗內容以誠實補全體系邊界。**意義**：正是因為選擇了公開成書而非僅止於私人心得，他的思想才得以在身後兩百年間發展為有組織的道派（南宗），並與全真北宗形成延續至今的理論對話。

## 思想演化軌跡

```
博覽三教經書、諸種方術
  → 長期任府吏，世俗身份中的知識積累

  ↓ 中年獲罪，謫戍嶺南（斷裂點）

尋道問道的轉向：
  → 隨陸詵入成都
  → 1069年遇真人授金丹藥物、火候之訣

  ↓ 六年沉澱與整理

《悟真篇》成書（1075）：
  → 真鉛真汞論：拆穿流俗丹經的隱語空談
  → 性命雙修、先命後性的修煉總綱
  → 鼎器-藥物-火候的三階次第系統化

  ↓ 命功系統的邊界浮現

晚年誠實補全：
  → 增附禪宗性宗內容，「教雖分三，道乃歸一」

  ↓ 1082年趺坐而化

身後兩百年：
  ├── 私授單傳：石泰→薛道光→陳楠→白玉蟾（南宗五祖成形）
  ├── 與全真北宗（先性後命）形成理論分野
  └── 清代被納入禪宗官方語錄體系，殊榮加身
```
