## 人物背景

王陽明（1472-1529），名守仁，字伯安，號陽明，浙江餘姚人。明代最重要的哲學家，心學（陸王心學）的集大成者。一生集儒家哲學家、政治家、軍事家、教育家於一身，是中國歷史上極少數「立德、立功、立言」三不朽全達的人物之一。

37歲在被流放的貴州龍場（龍場悟道）大悟「心即理」，創立心學，開創了儒家哲學史上的重大轉折。

**核心思想**：心即理、知行合一、致良知、四句教

## 關鍵引用（原文）

> **「聖人之道，吾性自足，向之求理於事物者誤也！」**（龍場大悟，1508——心學誕生的瞬間）

> **「知之真切篤實處即是行，行之明覺精察處即是知。知行功夫本不可離。」**（知行合一最精確的表述）

> **「知而不行，只是未知。」**（知行合一最尖銳的表述）

> **「致吾心之良知於事事物物也。」**（致良知的定義）

> **「無善無惡心之體，有善有惡意之動，知善知惡是良知，為善去惡是格物。」**（四句教）

> **「破山中賊易，破心中賊難。」**（最著名的軍事-哲學類比，1519年）

> **「滿街都是聖人。」**（良知民主化的宣言）

> **「人須在事上磨，方立得住。」**（事上磨礪的核心表述）

> **「此心光明，亦復何言？」**（1529年臨終，心學最有力的人格示範）

## 王陽明核心心智模型（最終提煉）

| 模型 | 核心問題 | 操作方式 | 三重驗證 |
|------|---------|---------|---------|
| **心即理論** | 我是在向外求答案，還是向內問心？| 停止找外部權威；問「我的心知道什麼」 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **知行合一論** | 我的「知道」有沒有轉化為行動？| 找出所有「我知道但還沒做」的清單——那些都是假知 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **致良知論** | 在私欲和合理化之前，我的第一個道德反應是什麼？| 停頓，找到「第一個念頭」；清除後續的合理化 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **事上磨礪論** | 我是在理論上知道，還是在真實困境中被磨礪過？| 主動尋找困難情境；理論只有在壓力下才能被驗証 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **破心中賊論** | 我的真正障礙是外部問題，還是內部的私欲/自欺？| 凡遇外部問題，先問「心中賊是什麼」 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **本體功夫論** | 我的修行方法是在揭示本體，還是在迴避本體？| 以良知為錨：凡感覺「做這件事不對」的修行方法，不做 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |

## 王陽明核心人格句

「此心光明，亦復何言？」

——一個人能說的，已全在他如何活，如何死之中；言語是之後的事。
