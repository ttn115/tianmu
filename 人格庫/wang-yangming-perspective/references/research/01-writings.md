# 王陽明（王守仁）— 著作與系統思考

## 調研說明

王陽明（1472-1529 CE，明代）的思想主要記錄於：
- **《傳習錄》**：學生記錄的師生問答，是心學最重要的一手文獻
- **《大學問》**：他對《大學》的詮釋，心學體系的系統闡述
- **《陽明全書》**：書信、奏疏、詩文的全集
- **年譜**（錢德洪等編）：記錄一生思想轉折的傳記

---

## 六個核心論點

### 論點一：心即理——原則不在物中，在心中（龍場大悟，1508年）

> 「聖人之道，吾性自足，向之求理於事物者誤也！」

**這是王陽明思想的基礎大爆炸。**

37歲被流放至貴州龍場（偏遠瘴癘之地），在極度孤獨和困境中徹夜靜思，突然大悟：

朱熹的「格物致知」要人在外部事物中尋找道德原則（先在竹子裡找竹的理，再在天地萬物中找萬物的理）——王陽明在22歲時曾照做，盯著竹子七天，什麼都沒找到，反而生了病。

龍場的大悟告訴他：**理不在事物之中，理就在我的心中。** 心本身就是道德原則的來源，而非接收站。

「心即理也。天下又有心外之事，心外之理乎？」（《傳習錄》）

**實踐意涵**：解決道德和認識問題，不需要先窮盡天下事物的學問；首先向內，問自己的心。

---

### 論點二：知行合一——真知必然帶來行動（1508年後開始教授）

> 「知之真切篤實處即是行，行之明覺精察處即是知。知行功夫本不可離。」
> 「知而不行，只是未知。」

這是他最廣為人知、也最常被誤解的主張。

**不是在說「知道要做什麼然後去做」**——那只是常識。

**他說的是**：如果你「知道」一件事而沒有去做，你的那個「知道」其實是假知道——只是概念熟悉度，不是真知識。

**舉例（來自《傳習錄》）**：「今人學知孝，學知弟，必其人已曾行孝行弟，方可稱他知孝知弟。不成只是曉得說些孝弟的話，便可稱知孝知弟？」

你「知道」應該孝順父母，但實際上從沒孝順過——你知道的只是「孝順」這個詞，不是孝順這件事。

**應用**：每一個行動的延遲，都是尚未真知的証据。每一個「我知道但是……」的藉口，都是自我欺騙的信號。

---

### 論點三：致良知——激活先天道德感知（晚年定論，1521年後）

> 「良知者，孟子所謂是非之心，人皆有之，不學而知，不慮而能。」
> 「致吾心之良知於事事物物也。」

這是王陽明最終的、最成熟的教義。他說：**良知是人人生來就有的道德感知能力。** 不需要外在學習，不需要老師告訴你。

問題不是「我不知道對錯」，而是「我的良知被私欲遮蔽了，說不出聲來」。

「致良知」= 去除私欲的遮蔽，讓良知在每件具體事上都能清晰地說話並被執行。

**邏輯**：
1. 良知人人皆有（孟子的「是非之心」）
2. 良知被私欲遮蔽（自我欺騙、自利動機、習慣性合理化）
3. 致良知 = 清除遮蔽 + 讓良知在每件事上完整發揮

「滿街都是聖人。」（《傳習錄》）——每個人都有完整的道德能力，不是少數有學問的人的專利。

---

### 論點四：四句教——思想的完整系統（1527年，天泉橋）

> 「無善無惡心之體，有善有惡意之動，知善知惡是良知，為善去惡是格物。」

這是王陽明去世前兩年，在天泉橋上對兩位主要弟子（王畿、錢德洪）的最終系統陳述。

逐句解析：
1. **無善無惡心之體**：心的本來狀態超越善惡二元（不是沒有道德，而是在善惡分別之前的原始狀態）
2. **有善有惡意之動**：一旦心動起念，就有善惡的分別
3. **知善知惡是良知**：良知的功能就是辨別善惡
4. **為善去惡是格物**：真正的「格物」不是在外物上找理，而是在每件事上做好去惡的工夫

這四句引發了後來「四句教之爭」：弟子王畿主張第一句可以頓悟（直接到達無善無惡的心體），錢德洪主張需要漸修（有善有惡的意念需要逐步工夫）。這個爭議持續了幾百年。

---

### 論點五：事上磨礪——只有真實情境才能產生真知（一貫立場）

> 「人須在事上磨，方立得住。方能靜亦定，動亦定。」

對於「先靜坐體悟再行動」的做法，王陽明明確反對。

他說：如果一個人只在靜坐中體悟道德，一旦遇到真實的困難（家庭壓力、政治風險、生死抉擇），就會立刻崩潰——因為那個「靜中的知」沒有在真實事件中被磨礪過。

**他自己的生命就是這個論點的証明**：被廷杖（差點打死）、被流放（流配蠻荒）、親自帶兵打仗——每一個極端處境都是他思想被「磨礪」的場所。

「苦難是哲學的實驗室」——王陽明的版本。

---

### 論點六：破心中賊難（最真實的一句）

> 「破山中賊易，破心中賊難。」
>（《與楊仕德薛尚謙書》，1519年鎮壓朱宸濠叛亂後）

這句話寫在他剛剛用43天平定一場叛亂之後。打了大勝仗——然後說「外面的賊好對付」。

「心中賊」= 自欺、私欲、合理化、懶惰、恐懼——這些才是真正的敵人。

**應用框架**：任何時候你覺得「問題在外部」，先問：「心中的賊是什麼？」

## 五個自創概念

### 1. 良知（Liangzhi）——先天道德感知

來自孟子，但王陽明大幅深化：良知不只是知道善惡，還**主動想要去做善、去除惡**。

良知是知、情、意、行的統一，不是純粹認知能力。

### 2. 心體（Xin Ti）——心的本來狀態

超越善惡分別之前的「心的本體」。王陽明的「四句教」第一句所指。

不是空洞——是充滿潛能的、「如明鏡」的狀態。

### 3. 格物（新詮釋）——在具體事物上做為善去惡的工夫

朱熹：格物 = 在外部事物上窮究其理。
王陽明：格物 = 在每件具體事（格，端正）上，讓良知的判斷完整發揮（物，事也）。

「格者，正也。正其不正以歸於正也。」

### 4. 私欲（Sī Yù）——遮蔽良知的干擾源

不只是「私人欲望」，而是一切阻止良知清晰運作的內部噪音：自我防衛、自我欺騙、合理化、習慣性偏見。

### 5. 本體功夫論（Běn Tǐ Gōng Fu）——本體與工夫的統一

對王陽明的一個核心批評是「你的工夫（修行方法）從哪裡來？」

他的回答：本體（心體、良知）本身就告訴你工夫怎麼做；工夫反過來揭示本體。二者不可分離。

## 思想體系結構

```
心（本體）
  ├── 心即理（心中包含所有道德原則）
  ├── 良知（心的道德感知功能，人人先天具有）
  └── 心體（超善惡的本來狀態）

       ↓ 問題：私欲的遮蔽

致良知（去除遮蔽的功夫）
  ├── 事上磨礪（只有真實情境才能真磨礪）
  ├── 省察克治（自我審察，清除私欲）
  └── 知行合一（真知 = 知+行，二者不可分）

       ↓ 結果

聖人（不是道德完人，而是良知暢通無阻的狀態）
  └── 「滿街都是聖人」——人人可達
```

## 智識譜系

**繼承**：
- 孟子（良知良能的原始概念）
- 陸九淵（「心即理」的先驅：「宇宙便是吾心，吾心便是宇宙」）
- 禪宗（頓悟模式、直指本心）——雖然他否認，但影響明顯

**批判性對話**：
- 朱熹（格物窮理的反論點：不在事物中找，在心中找）

**後代的繼承與發展**：
- 王畿：發展「現成良知」說，傾向頓悟
- 錢德洪：強調漸修工夫，反對王畿的激進化
- 泰州學派（王艮、何心隱）：「日用即道」，把陽明學普及到農民、工匠
- 李贄：用陽明學走向了極端個人主義
- 日本陽明學：吉田松陰、佐藤一斎——直接影響明治維新

|------|---------|---------|---------|
| **心即理論** | 我是在向外求答案，還是向內問心？| 停止找外部權威；問「我的心知道什麼？」| ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **知行合一論** | 我的「知道」有沒有轉化為行動？| 找出所有「我知道但還沒做」的清單——那些都是假知 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **致良知論** | 在私欲和合理化之前，我的第一個道德反應是什麼？| 停頓，找到「第一個念頭」；清除後續的合理化 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **事上磨礪論** | 我是在理論上知道，還是在真實困境中被磨礪過？| 主動尋找困難情境；理論只有在壓力下才能被驗証 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
