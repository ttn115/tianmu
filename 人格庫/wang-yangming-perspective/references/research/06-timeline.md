# 王陽明（王守仁）— 人生時間線

---

## 時間線

| 時間（年齡）| 事件 | 思想意義 |
|------------|------|---------|
| **1472年**（0歲）| 生於浙江餘姚，父王華後成為進士第一（狀元）| 士大夫精英家庭，從小接受最高規格的儒家教育 |
| **約1484年**（12歲）| 問老師：「什麼是人生最重要的事？」老師說考科舉；他說「也許是做聖人」| 最早的志向記錄：不以功名為目標，以成聖為目標 |
| **約1489年**（17歲）| 大量讀朱熹著作；開始按朱熹「格物致知」方法修行 | 正式進入程朱理學體系 |
| **約1489年**（17-22歲）| 「格竹七日」：與朋友嘗試「格竹子的理」，守了7天，病倒，一無所獲 | 第一次哲學危機：朱熹方法論的失敗 |
| **1494年**（22歲）| 首次應鄉試，落第 | — |
| **1499年**（27歲）| 通過會試，成進士；初入官場 | 正式仕途開始 |
| **1504年**（32歲）| 在北京工部和兵部任職，開始小規模教學，思想逐漸成形 | 政治-學術生涯並行 |
| **1506年**（34歲）| **廷諫劉瑾**：上疏替被迫害的戴銑等人辯護 → 被廷杖四十大板 → 流配貴州龍場驛 | 第一個重大決策：知道危險仍然行動（知行合一的初步示範）|
| **1507-1508年**（35-37歲）| **流放龍場**：偏遠瘴癘之地，貧病孤苦，自建石墩為枕，思考人生根本問題 | 哲學危機的最深點：一切外部支持都消失了 |
| **1508年**（37歲）| **龍場悟道**：夜間突然大悟——「聖人之道，吾性自足，向之求理於事物者誤也！」| **思想史最重要時刻**：心學誕生；「心即理」確立 |
| **1508-1510年**（37-38歲）| 在龍場開始教導當地夷族人，開設書院；開始傳授「心即理」和早期「知行合一」| 教學傳道的開始；打破文化階級的先兆 |
| **1510年**（38歲）| 劉瑾被誅；王陽明調回京任職，陞官；知行合一開始廣泛傳播 | 政治翻轉；心學公開傳播期 |
| **1513-1516年**（41-44歲）| 在滁州、南京等地任官，持續教學，學生日眾 | 傳習錄中大量對話記錄於此期間 |
| **1516-1519年**（44-47歲）| 出任江西巡撫，督軍平定多起地方叛亂（湖廣、廣東、江西各地）| 軍事-哲學並行：「事上磨礪」有了真實軍事內容 |
| **1519年**（47歲）| **43天平定寧王朱宸濠叛亂**：自行動員民兵，使用欺敵戰術，以弱勝強 | 「致良知」在政治-軍事上的頂點示範；「破山中賊易，破心中賊難」此時所寫 |
| **1519年後**（47歲後）| 平亂功勞被政治對手質疑；被明武宗懷疑（武宗親自出征要「搶功」，後被勸阻）| 不爭功；承受冤枉；心中賊的試煉 |
| **1521年**（49歲）| **「致良知」正式成為核心教義**，在學生的記錄中出現「致良知」三字作為最終定論 | 思想系統的成熟完結 |
| **1521-1527年**（49-55歲）| 主要在浙江、江西等地任官、教學；門人數千，影響廣至各省 | 心學最盛時期；《傳習錄》大部分記錄於此期間 |
| **1527年**（55歲）| **天泉橋四句教**：出征廣西前，對王畿和錢德洪作最後的系統哲學陳述——四句教 | 哲學遺言；為後學兩條路徑的爭論埋下種子 |
| **1527-1528年**（55-56歲）| 帶病出征廣西，平定廣西少數民族衝突 | 病重仍出征：「事上磨礪」到生命最後 |
| **1529年1月**（56歲）| **逝世**於從廣西回程的船上（江西大余）；臨終弟子問遺言，答：「此心光明，亦復何言？」| 五字臨終語，成為心學最有力的人格示範 |

## 三個關鍵轉折點

### 轉折一：格竹失敗——朱熹方法論的崩潰（22歲）

不是「格竹事件」本身，而是**他對這個失敗的反應**。

大多數人在一個方法失敗後，會放棄這個方法，或者放棄整個問題。王陽明的反應是：**這個方法一定哪裡根本性地錯了，我要找出來是哪裡。**

這個「找出根本錯誤的執著」，15年後在龍場給出了答案。

---

### 轉折二：龍場大悟——從外部找到內部（37歲）

龍場不是冥想禪修的環境——是貧病孤苦的極限。

王陽明的大悟有三個條件：
1. 外部支持完全消失（書、老師、朝廷、家人）
2. 生死威脅使問題變得真實（瘴氣可以隨時殺死他）
3. 多年積累的問題在壓力下突然聚焦

「只有在喪失一切外部依賴後，才發現了在心中一直存在的答案。」

這不只是哲學故事，而是他「事上磨礪」和「心即理」最完美的個人示範。

---

### 轉折三：天泉橋四句教——接受不完整性（55歲）

他的最後一次系統哲學陳述沒有「終結爭議」，反而「允許爭議繼續」。

這個選擇顯示了一種成熟：不強迫統一，接受不同人走不同路。這本身就是「良知民主化」的終點——連哲學解釋都可以有多條路，不必是一條。

## 思想演化軌跡

```
少年：立志成聖（不以功名為目標）
  → 格竹失敗 → 程朱方法不可行

  ↓ 17年的摸索（讀書、任官、失敗）

龍場大悟（37歲）：
  → 心即理（第一個基礎）
  → 知行合一（第一個方法）
  → 開始教學

  ↓ 平定叛亂、戰場磨礪（44-47歲）

思想成熟期：
  → 「致良知」成為核心（49歲）
  → 事上磨礪：軍事証明了哲學

  ↓ 廣泛教學、學生分化

晚年定論：
  → 四句教（55歲）：接受多條路並存
  → 「此心光明」（56歲）：用死亡示範了一切

後代：
  ├── 王畿路線 → 頓悟 → 李贄 → 個人主義
  ├── 錢德洪路線 → 漸修 → 保守傳統
  └── 泰州學派 → 平民化 → 明治維新 → 日本近代化
```

## 文化背景補充

**明代中期的思想危機**

王陽明生活在明代中期（弘治-正德-嘉靖年間），這個時代的程朱理學已經高度教條化——讀書是為了科舉考試，不是為了真正實踐道德。儒家的外在形式（禮制、學問）和內在道德修行高度脫節。

王陽明的「心學」正是對這個「知行分裂」的文化現象的回應——儒家說「格物致知」，但實際上每個人都在考試，沒有人真的在格物。

**太監（宦官）專政的政治背景**

正德年間的「劉瑾之禍」是王陽明悲劇的外部原因，也是他哲學轉折的外部觸發器。沒有劉瑾就沒有廷諫，沒有廷諫就沒有流配龍場，沒有龍場就沒有大悟。

一個奸宦的政治迫害，製造了中國思想史最重要的大悟。
