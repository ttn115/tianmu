## 人物背景

孫武（字長卿，約公元前545-470年，齊國人），《孫子兵法》作者，春秋末期軍事家，經伍子胥推薦見吳王闔閭，助吳破楚入郢，柏舉之戰以少勝多。與扁鵲、希波克拉底類似，其生平記載帶有相當程度的傳說渲染，1972年銀雀山漢墓竹簡出土確證孫武、孫臏為兩個不同的真實歷史人物，但今本《孫子兵法》很可能經歷了戰國時期的層累增補。

**核心定位**：本庫**戰略/衝突思維**領域唯一代表，填補了此前完全空白的一個維度——全書僅約6000字卻建立起涵蓋戰略、後勤、情報、地形、心理、指揮體制的完整決策框架，是全球知名度最高、可遷移性最強的思維源頭之一。

## 信息缺口

- 孫武確切生卒年三說並存，晚年下落（歸隱/被誅）史料互相矛盾
- 「吳宮教戰」典故的真實性自宋代起即受質疑，《左傳》詳載柏舉之戰卻隻字未提孫武

## 關鍵引用（原文）

> **「知彼知己，百戰不殆；不知彼而知己，一勝一負；不知彼，不知己，每戰必敗。」**（謀攻篇——核心人格句候選）

> **「是故百戰百勝，非善之善者也；不戰而屈人之兵，善之善者也。」**（謀攻篇）

> **「兵者：詭道也。」**（始計篇）

> **「昔之善戰者，先為不可勝，以待敵之可勝。不可勝在己，可勝在敵。」**（軍形篇）

> **「故兵貴勝，不貴久。」**（作戰篇）

> **「兵無常勢，水無常形，能因敵變化而取勝者，謂之神。」**（虛實篇）

## 與同類人物的比較

| 維度 | 孫子 | 塔勒布 | 芒格 | 稻盛和夫 |
|------|--------|--------|--------|--------|
| 核心方法 | 資訊優勢+動態適應的系統性框架 | 反脆弱、不對稱下注 | 多元思維模型、逆向思考 | 樸素道德判準優先 |
| 決策錨點 | 代價-效益精算 | 生存優先、避免毀滅 | 跨學科交叉驗證 | 「作為人，何謂正確」|
| 表達策略 | 精煉格言體、系統化框架 | 案例+警句+挑釁性反詰 | 格言集+個人幽默直率批判 | 箴言體、近乎宗教語言 |

**關鍵觀察一（與塔勒布的方法論對照，本庫在「不確定性下決策」議題上最鮮明的一組東西方對比）**：孫子透過情報與預先部署「壓縮」不確定性、掌握主動權，是**主動預測與控制**的思維；[[塔勒布]]的反脆弱主張放棄精確預測、建構在混亂中受益的系統韌性，是**擁抱不可預測性**的思維。

**關鍵觀察二（與芒格的方法論呼應）**：[[芒格]]的「思維格柵」與孫子十三篇同樣是多維度、互相制約的模型集合，都反對套用任何單一僵化公式，差異在於芒格的模型庫橫跨現代學科譜系，孫子的模型庫收斂於衝突與競爭這一垂直領域。

**關鍵觀察三（與稻盛和夫的決策錨點對照）**：孫子的決策起點是「代價-效益」的精算，[[稻盛和夫]]的決策起點則是「作為人，何謂正確」這類樸素道德判準——是本庫在「如何做重大決策」議題上一組值得對照的東方思維範例。

## 孫子核心心智模型（最終提煉）

| 模型 | 核心問題 | 操作方式 | 三重驗證 |
|------|---------|---------|---------|
| **不戰而屈人之兵論** | 這場對抗，有沒有辦法讓對方根本不需要一戰就放棄？| 優先考慮謀略/外交等低代價路徑 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **知彼知己論** | 我對自己和對手的了解，是否足夠支撐這個決策？| 行動前系統性盤點雙方資訊 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **詭道論** | 除了直接能力對抗，是否存在管理對方認知的額外槓桿？| 主動製造對方誤判，創造出其不意的優勢 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **先為不可勝論** | 追求贏之前，是否已經確保了不會輸？| 優先鞏固自己完全可控的部分 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **兵貴勝不貴久論** | 這件事拖得越久，是否正在反過來拖垮我自己？| 優先選擇足夠好但夠快的方案 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **兵無常勢論** | 我是在主動設定局勢，還是被動被對方牽著走？| 放棄固定打法，依局勢動態調整 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |

## 孫子核心人格句

「知彼知己，百戰不殆。」

——兩千五百年來被引用最多的中國格言之一。他把戰爭這件最極端、最高風險的人類活動，拆解成一套可以被系統性學習的決策框架——資訊優勢、效益排序、風控原則、資源約束、動態適應。這套框架的生命力，恰恰在於它從未承諾「必勝」，只承諾「不殆」——這種誠實的克制，或許才是它跨越兩千五百年仍未過時的真正原因。
