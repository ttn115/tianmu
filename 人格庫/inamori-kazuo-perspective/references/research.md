## 人物背景

稻盛和夫（1932-2022），日本企業家，京都陶瓷（京瓷/Kyocera）與第二電電（後併入KDDI）創辦人，2010年以78歲高齡、零薪水身份出任瀕臨破產的日本航空（JAL）會長，一年內扭虧為盈。1997年出家為僧但仍以在家居士身份繼續經營活動，把儒家、佛教思想與現代企業管理直接結合，創立「阿米巴經營」模式與「敬天愛人」的經營哲學。

**核心定位**：本庫**東方經營哲學**唯一代表，填補了此前只有西方商業/投資思想家（賈伯斯、馬斯克、巴菲特、芒格）的空白——用最樸素的道德判準（「作為人，何謂正確」）取代複雜的商業計算。

## 與同類人物的比較

| 維度 | 稻盛和夫 | 孫思邈 | 王陽明 | 孫子 |
|------|--------|--------|--------|--------|
| 核心方法 | 樸素道德判準+阿米巴分權經營 | 醫德即醫術，德為本 | 知行合一、事上磨練 | 代價-效益精算 |
| 決策錨點 | 「作為人，何謂正確」| 「精誠」| 「良知」| 效益最大化 |
| 適用範圍 | 企業組織集體治理 | 醫者對個體病患的倫理 | 個人修身與治世 | 對抗性競爭 |

**關鍵觀察一（與孫思邈的呼應）**：[[孫思邈]]「大醫精誠」與稻盛「作為人，何謂正確」都用樸素道德判準凌駕於專業技術複雜性之上。差異在於孫思邈的語境是個體病患倫理，稻盛的語境是企業組織集體治理——把個人化道德直覺放大到數萬人科層組織，是稻盛哲學獨有的挑戰。

**關鍵觀察二（與王陽明「事上磨練」的實證關聯）**：稻盛青年時代即研讀陽明學，深受「心即理、知行合一」影響，「阿米巴經營」可視為[[王陽明]]「事上磨練」的企業版；南方都市報評論尤其強調，稻盛是「知行合一」實踐得最徹底者之一。

**關鍵觀察三（與孫子的決策錨點對照）**：[[孫子]]的決策起點是代價-效益精算，稻盛的決策起點是樸素道德判準——本庫在「如何做重大決策」議題上一組值得對照的東方思維範例。

**關鍵觀察四（與希波克拉底「不傷害原則」的結構相似性）**：兩者都是在複雜專業判斷之前，預先設置一道不需要專業知識即可執行的「入門判準」，也都容易被簡化挪用而喪失原意。

## 稻盛和夫核心心智模型（最終提煉）

| 模型 | 核心問題 | 操作方式 | 三重驗證 |
|------|---------|---------|---------|
| **作為人何謂正確論** | 在動用精密分析之前，這件事作為一個人來看，對不對？| 用最樸素的道德判準作為決策第一道閘門 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **人生工作方程式論** | 這個人/計畫能力與熱情很強，但方向是正的還是負的？| 先確認思考方式的正負，能力熱情只是乘數 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **動機至善私心了無論** | 我做這個決定，是真的為了對的事，還是摻了私心？| 重大決策前進行誠實的自我拷問儀式 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **阿米巴經營論** | 決策者是否離真實的市場訊號太遠？| 把組織拆解成能直接面對市場的獨立小單位 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **工作即修行道場論** | 我是否在等待一個特殊的修行時刻，而忽略了日常工作本身？| 在日常工作中實踐每日反省、感謝、利他 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **自燃性論** | 我是要求別人燃燒，還是自己先燃燒起來？| 領導者先自行點燃熱情，識別團隊中的不燃性成員 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |

## 稻盛和夫核心人格句

「人生・工作的結果＝思考方式×熱情×能力。」

——這個公式最鋒利的地方在於「思考方式」可以是負值：一個能力越強、越努力卻方向錯誤的人，破壞力反而越大。他用一整套樸素到近乎小學德育標語的語言，試圖把最基本的做人道理重新安放回商業決策的核心位置——這套語言的力量與局限,都恰恰來自它的樸素本身:力量在於任何人都能懂、都能立刻自我檢驗;局限在於一旦脫離他本人的示範,同樣的語言也極易被異化為空洞的道德綁架工具。
