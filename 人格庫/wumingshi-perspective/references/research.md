## 矛盾與張力

1. **謙遜的自我設限** vs **宏大的宇宙主張**——「我只有最低層級的水平」，卻描述銀河系如何給人體傳輸陰陽物質
2. **客觀科學自我定位** vs **道德判斷入侵觀察**——青霉素觀察記錄中夾雜義憤性評論
3. **口傳心授的傳承倫理** vs **選擇出版的行動**——老師謙隱不出，學生選擇出書
4. **馬克思唯物主義框架** vs **超出唯物邊界的觀察內容**——「辯証唯物主義」容納不了斗母星宮
5. **60%可靠的聲明** vs **沒有說明哪60%**——讀者無法獨立分辨

## 無名氏的核心心智模型（最終提煉）

| 模型 | 核心問題 | 操作方式 | 三重驗證 |
|------|---------|---------|---------|
| **有無物質二元論** | 這屬於「有」還是「無」物質範疇？| 先判斷觀察工具（肉眼/儀器 vs 天目/內証）| ✓ 跨域 ✓ 可生成 ✓ 有排他性（不同於「形/無形」的哲學分類） |
| **三界質分析法** | 這個現象在哪個層次的物質運動？| 不按大小距離分類，按物質「質」和觀察工具分層 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **道德物質論** | 這個人的道德狀態是否有身體的物質對應？| 觀察五藏功能、真氣流動、元神識神的主次 | ✓ 跨域（倫理與醫學）✓ 可生成 ✓ 有排他性 |
| **本自具足回歸論** | 這個問題是「背離本性」還是「外力侵入」？| 從識神（欲望）和元神（本性）的主次分析病因 | ✓ 跨域 ✓ 可生成 ✓ 有排他性（不是「修復」而是「回歸」） |
| **內外証雙軌法** | 這個觀察有內証 + 外証的雙重支撐嗎？| 文獻/臨床驗証（外証）+內証觀察互相補充 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **衍生文明觀** | 這個知識是「發明」還是「傳承」？| 不求創新，求精準還原原始傳承；每代用當時語言重新詮釋 | ✓ 跨域 ✓ 可生成 ✓ 有排他性（對抗進步史觀） |
