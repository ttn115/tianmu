# 王德槐 — 人生時間線

## 說明：當代人物但公開生平資料稀疏

王德槐為台灣當代丹道實修者，生卒年等基本資料在公開來源中不完整，本時間線以《中國仙道之究竟》自述與二手記載為主，存疑處如實標注，未做多來源交叉考證。

---

## 時間線

| 時間 | 事件 | 意義 |
|------|------|------|
| 早年 | 任財政部關政司司長（公務員生涯）| 樸實、條理、給步驟的表達風格底色 |
| 早年 | 五龍門余雪鴻老師門下啟蒙 | 有師承的實修起點 |
| **1987 年**（⚠️ 原作 1977，已更正）| 第一次出陽神，之後四處尋師不得 | 「先練站樁、走過的彎路不讓後人走」的直接源頭 |
| 中後期 | 放棄依賴師承，轉走文始派、靠古籍自學 | 從師承依賴轉向身體實驗與自學 |
| 約 1988 | 《中國仙道之究竟》第一集《內金丹法》初版（247頁）| 開始把個人練功心得公開出版 |
| 2006 | 第四集《天仙心傳》(04)、第三集《女金丹法》(09)、第六集《文始真經新釋》(11) 密集出版 | 站樁問答收於第四集；系列主體成形 |
| 2008–2011 | 《修仙寶典（天機秘文）》(2008)、第五集《現代道家養生法》(2010)、《未來預知術》(2010)、第一二集再版(2011) | 全六集與延伸著作陸續補齊（皆自費出版）|
| 多年試錯後 | 三種樁式一一試過，選定下按式 | 「身體投票、做得出才算數」的方法定型 |
| （時點不詳）| 李嗣涔腦波實驗：一閉口 α 波降為 0 | 罕見外部觀測，印證「入靜近乎關機」的狀態 |
| **至 2002 年** | 門下據稱出陽神 4 人、大周天數十人、通小周天逾百人 | 門內自述，無外部驗證（宣稱層，需打折）|

## 已補（2026-08-26 網路書目查證）

《中國仙道之究竟》全六集皆王德槐自費出版：一《內金丹法》(約1988初版/2011再版)、二《性命篇》(2011)、三《女金丹法》(2006-09)、四《天仙心傳》(2006-04，站樁問答所在)、五《現代道家養生法》(2010-05)、六《文始真經新釋》(2006-11，ISBN 9789574141449，280頁)。另著《修仙寶典（天機秘文）》(2008)、《未來預知術》(2010)。
