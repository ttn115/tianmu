# 《金剛經》作者 — 時間線

## 重要說明：這是「文本的時間線」，不是「一個人的時間線」

**匿名撰者無生平可考。** 但這條文本流傳史本身極為清晰——**而且與《楞嚴經》那條充滿爭議的時間線形成鮮明對照。**

## 時間線

| 時間 | 事件 | 意義 |
|---|---|---|
| **約公元 2–5 世紀** | 梵文原典 *Vajracchedikā Prajñāpāramitā Sūtra* 於印度成立。**撰者不明，年代學界無定論** | 屬般若系文獻，非孤立文本 |
| **401/402 年** | **鳩摩羅什**於長安譯出《金剛般若波羅蜜經》 | **決定漢傳面貌的一譯**；他自述翻譯「有似嚼飯與人」 |
| 509 年 | 菩提流支譯 | 第二譯 |
| 562 年 | 真諦譯 | 第三譯 |
| 590 年 | 達摩笈多譯 | 第四譯，極度直譯 |
| **648 年** | **玄奘**譯，收於《大般若經》第九會「能斷金剛分」 | **更貼近梵文原意，但幾乎無人誦讀** |
| 703 年 | 義淨譯 | 第六譯 |
| 唐初 | **五祖弘忍以《金剛經》代替《楞伽經》授徒** | 此經成為禪門根本典籍的關鍵制度性轉折 |
| 唐 | **[[慧能]]聞「應無所住而生其心」而開悟** | **本庫中最短、最可考的一條開悟因果鏈**——而那個句法是鳩摩羅什的選擇 |
| **868 年（唐咸通九年）** | 敦煌本《金剛經》刊印，卷末題「王玠為二親敬造普施」 | **目前已知世界上最早的有明確紀年的印刷書籍**，今藏大英圖書館 |
| 歷代 | 註疏極盛：僧肇、智顗、慧能《口訣》、宗密、六祖以下禪門諸家 | 為填補「只給判準不給步驟」的空缺 |
| 近現代 | **真偽爭議極小**——梵本、藏譯、六種漢譯並存，可三方對照 | **與《楞嚴經》處境截然相反** |

## 三個關鍵節點

### 節點一：401/402年鳩摩羅什的翻譯——一次改變後續一千六百年的選擇

他明知「改梵為秦……有似嚼飯與人，非徒失味，乃令嘔噦」，**仍選擇了意譯與可讀性。**

**意義**：六譯之中，**學術上最嚴謹的玄奘本幾乎無人誦讀，最具文學節奏的羅什本近乎壟斷。**

**這件事本身就是一個關於傳播的殘酷事實：可讀性壓倒準確性。**

**而它恰好與經文自身立場形成呼應**——文字本來就只是「是名」而已，執著於哪一版更「準確」，本身就落了相。

### 節點二：弘忍以《金剛經》代《楞伽經》——一次制度性的選擇

禪宗初期以《楞伽經》為心要，**五祖弘忍改用《金剛經》授徒。**

**意義**：這一步把一部五千字的短經，推上了整個中國禪宗的根本位置。**若非這個決定，慧能也不會在那個時刻聽到那句話。**

### 節點三：慧能因一句話開悟——譯者的用字，促成了另一個人格

**「應無所住而生其心」。**

玄奘作「都無所住應生其心」，義淨作「不住於法應生其心」——**同義，異節奏。**

**意義**：本庫中，[[慧能]]是[[老子]]、[[王陽明]]之外最常被引用的東方人格之一，而**他的起點是一個譯者的措辭選擇。**

**這是「翻譯者的權力」最清楚的案例，也是本庫少數可以精確指出「某一句話造就了某一個人」的地方。**

## 文本流傳軌跡

```
約2–5世紀 印度：匿名大乘撰述（般若系）
  │  梵本 Vajracchedikā Prajñāpāramitā Sūtra
  │
  ├─→ 藏譯本 ────────────┐
  │                        │ 三方可對照
  └─→ 漢譯六種 ───────────┘
        ├── 401/402 鳩摩羅什 ★ 意譯，可讀性優先
        │     └→ 唐初 弘忍以此經代《楞伽》授徒
        │           └→ 慧能聞「應無所住而生其心」開悟
        │                 └→ 《壇經》「本來無一物」
        │                       └→ 中國禪宗
        ├── 509 菩提流支
        ├── 562 真諦
        ├── 590 達摩笈多（極度直譯）
        ├── 648 玄奘（最貼近梵文，幾乎無人誦讀）
        └── 703 義淨

868年 敦煌刊本 → 世界最早有紀年的印刷書籍（大英圖書館）
```

**注意這張圖與《楞嚴經》那張的差別**：楞嚴那張的主軸是**爭議史**（朱熹→梁啟超→呂澂→辯護方），**至今無定論**；
**金剛經這張的主軸是流傳史**——**它從來不需要為自己的真偽辯護，它只需要被讀。**
