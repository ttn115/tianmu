## 決策一：造一個經文裡沒有的詞

| | |
|---|---|
| **選擇** | 用「**治身**」當作貫穿全書的軸 |
| **可測的事實** | 經文 **0 次**、另一家註者 **0 次**、他 **32 次**（p=1.5e-06，期望 14.0） |
| **他自己的說明** | 「**說聖人治國與治身同也。**」 |
| **代價** | ⚠️ **他沒有給這個對應的判準**——為什麼「愛民」對應「愛氣」，他只給對子不給理由 |
| ⚠️ **本庫的收緊** | **他加的是一半**：「治國」老子本來就有（4 次） |

**→ 可遷移的形狀**：*任何對外的原則，先問它對內那一半是什麼。*
⚠️ **而這個格式沒有自我約束——任何一句話都能被雙讀。**

## 決策二：替 81 個沒有名字的章命名

| | |
|---|---|
| **選擇** | 體道・養身・安民・無源・虛用……（81 個） |
| **對照** | 王弼本只有編號 |
| ⭐ **命名的傾向** | **大量是修身的動詞短語**：養身・能為・檢慾・厭恥・益謙・儉欲・貴生・養德・愛己・戒強・忘知・修觀 |
| ⚠️ **瑕疵** | 「**淳風**」用了兩次（道經第 17、德經第 20）——**81 個名字不是全不重複** |
| ⚠️ **限制** | **章名的來源本庫未查證**，無法確定全是他本人所題 |

**→ 可遷移的形狀**：*替無名的東西命名，而名字要用動詞——名字本身就是你的讀法。*

## 決策三：切 931 刀，而不是 405 刀

| | 他 | 王弼 |
|---|--:|--:|
| 註條 | **931** | 405 |
| 每章 | **11.5** | 5.0 |
| 中位數 | **14 字** | 18 字 |
| 最長一條 | **117 字** | **1,063 字** |

⭐ **他的選擇是「均勻」**：每一句都切一刀，每一刀都差不多長。
**王弼的選擇是「不均勻」：大部分更短，偶爾停下來寫一篇 1,063 字的論文。**

⚠️ **代價已測得**：「謂」70.4/萬（王弼 39.8）——**大量註條只是「某謂某也」的換詞，不是論證。**

**→ 可遷移的形狀**：*切細讓覆蓋率高，而短的解釋容易退化成換同義詞。*

## 決策四：把抽象詞換成可以動手的字

| | 選的 | 沒選的 |
|---|---|---|
| **用** | **精（6.26×）、氣（7.19×）、神（3.26×）** | — |
| **沒用** | — | **解剖學**：髮 0、胎 0、血 1、齒 2、五臟 3 |
| ⚠️ **誤判過** | 「形」——**王弼用得更多**（50.0 vs 27.0，p=2.8e-03），**已從證據中移除** |

⭐ **最具體的一步**（釋「天門開闔」）：
> 「天門謂北極紫微宮……**治身之天門謂鼻孔，開謂喘息也，闔謂呼吸也。**」
**——他把經文最抽象的一句接到呼吸上。**

**→ 可遷移的形狀**：*不解釋大詞是什麼，換成三個你可以對它做事的小詞。*

## 決策五：講不通的時候給生活裡的比喻

**「喻」9.2/萬（王弼 1.7，5.4 倍，⚠️ 期望 7.0，支撐較弱）**，而實例很具體：
> 「烹小魚不去腸、不去鱗、不敢撓，恐其糜也。」
> 「糞者，糞田也……治身者卻陽精以糞其身。」

⚠️ **代價**：**比喻會把問題講小**——「烹小魚」好記，**而它不解釋為什麼煩則精散。**

**→ 可遷移的形狀**：*講不通就給生活裡的比喻，不要給更抽象的詞。*

## 決策六：不引任何人

**已逐一驗過**：931 條註裡「或曰」「子曰」「傳曰」「經曰」「詩曰」**皆 0 次**；
唯二兩處「曰：」都是他自己的「故曰：」（全書「故曰」僅 **5** 次）。

⚠️⚠️ **而這不是他的個人特徵**：**王弼註同樣 0 次引人名。**
**→ 本庫把它列為「兩家共有的體例」，不是他的決策。**
⭐ **可報告的差別在「故曰」**：他 5 次，**王弼 86 次（16 倍）**——**王弼才是那個不斷下結論的人。**
