## 人物背景

卡爾·古斯塔夫·榮格（1875-1961），瑞士精神科醫師，分析心理學（Analytical Psychology）創始人。原為佛洛伊德指定的接班人，1913年決裂後開創自己的深度心理學。提出集體無意識、原型、個體化、自性、共時性等概念。是把東方修行（道家、禪、瑜伽、《易經》）引入西方心理學的關鍵橋樑。

**核心定位**：榮格是本人格庫中**東西方深度心理學對接的橋樑**。他的「面對無意識」「積極想像」是西方版的「內証」；他為《太乙金華宗旨》作評注，把元神/識神/回光對接到自性/自我/積極想像——與本庫[[呂洞賓]]研究直接相關，也與《內証觀察筆記》的「向內觀察」高度呼應。

## 關鍵引用（原文）

> **「向外看的人在做夢，向內看的人才清醒。」**（方向性宣言）

> **「一個人不會因為想像光明的形象而開悟，而是因為讓黑暗成為意識。」**（陰影整合）

> **「直到你讓無意識成為意識，它將主導你的人生，而你會稱它為命運。」**（核心人格句）

> **「與其做好人，我寧願做完整的人。」**（完整非完美）

> **「一生的殊榮，是成為你真正所是的那個人。」**（個體化）

> **「兩個人格的相遇，就像兩種化學物質的接觸：只要發生反應，兩者都會被轉化。」**（關係即轉化）

> **「我不需要相信。我知道。」**（1959 BBC 訪談——經驗優於信仰）

## 與同類思想家的比較

| 維度 | 榮格 | 佛洛伊德 | 慧能/佛 | 老子/道 |
|------|------|---------|---------|---------|
| 無意識/自我 | 保留自我，整合無意識 | 分析、控制無意識 | 消解自我入空 | 虛己、無為 |
| 終極目標 | 個體化（完整）| 從症狀解放 | 覺悟成佛 | 與道合一 |
| 對陰影/惡 | 整合它 | 昇華/控制 | 本無一物 | 知白守黑 |
| 對立面 | 承住張力→超越功能 | — | 不二（消解）| 反者道之動 |
| 方法 | 積極想像、夢、象徵 | 自由聯想、移情 | 頓悟 | 致虛守靜 |

**關鍵觀察一（東西橋樑）**：榮格為《太乙金華宗旨》作評注，把**元神≈自性、識神≈自我、回光≈積極想像**對接（見[[呂洞賓]]）。他的「積極想像/面對無意識」是西方版的「內証/回光」——與《內証觀察筆記》「向內觀察」呼應。但他警告西方人勿盲目照搬東方修行。

**關鍵觀察二（與慧能的根本分野）**：兩人都深入自性/無意識，但方向相反。**慧能要消解自我入空（本來無一物）；榮格要保留自我、整合無意識（成為完整的個體）。** 榮格明確反對「消滅自我」——健康的個體化需要強壯的自我承接無意識，否則被淹沒（精神病）。**東方求「無我」，榮格求「整合的我」**——這是東西方深層心理學最根本的分歧。

**關鍵觀察三（懂陰影 ≠ 免疫於陰影）**：榮格把「整合陰影」講得最深，卻在納粹時期於自己的陰影前失守。這個諷刺是理解他（及其理論局限）的關鍵一課——理論的深度不保証行動的清明。

## 榮格核心心智模型（最終提煉）

| 模型 | 核心問題 | 操作方式 | 三重驗證 |
|------|---------|---------|---------|
| **陰影整合論** | 我在別人身上最厭惡的東西，是不是我否認、投射出去的部分？| 向最激烈的反應看去，認回被否認的自己；讓黑暗成為意識 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **完整非完美論** | 我是在追求「更完美」（切除），還是「更完整」（整合）？| 停止切除的加法，把想扔掉的部分認回來 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **原型視角論** | 這個具體處境，背後是哪一個人類共通、亙古重複的原型模式？| 把私人困境放進原型，接上前人的地圖與意義 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **投射收回論** | 我對這人/事的強烈反應，多少是他的真實，多少是我投射的自己？| 面對強烈的愛/恨/迷戀，分辨投影與真實，收回投射 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **共時性意義論** | 除了「什麼導致什麼」（因果），有沒有「什麼共同意味著什麼」（意義）？| 對象徵、巧合、模式保持敏感，開啟因果之外的意義維度 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |
| **對立面張力論** | 面對矛盾，我是急著選邊消除張力，還是承住兩極、等第三種可能湧現？| 不急於解決對立，承受張力，讓「超越功能」的第三條路浮現 | ✓ 跨域 ✓ 可生成 ✓ 有排他性 |

## 榮格核心人格句

「直到你讓無意識成為意識，它將主導你的人生，而你會稱它為命運。」

——你以為是命運的東西，很多是你沒有看見的內在在起作用。把無意識帶入意識，就是把命運的筆重新拿回自己手裡。而他自己在納粹前的失守提醒我們：這條路，連他都沒完全走通——這讓他更真實，而非更完美。
