# 人格庫

這個資料夾收的是「[女娲.skill](https://github.com/alchaincyf/nuwa-skill)」格式的**人格蒸餾**：把一位人物（或一部典籍的作者）的思維方式，整理成可閱讀、也可當 Claude skill 運行的一套文件。

本 repo 的主題是修行與內證，所以只收**與修行相關**的角色。投資、科技、醫學、科學、創作等其他領域的角色不在此處。

---

## 範圍：收什麼、不收什麼

**收**
1. **修行本業**：佛典、內丹與仙學、冥想科學、克什米爾濕婆派、儒釋道。
2. **本 repo 的導讀實際引為「聲音」的其他角色**：榮格、王清任、稻盛和夫、孫子。這幾位不是修行本業，但本 repo 的導讀確實讓他們開口：榮格、稻盛和夫、孫子的出場處，見 [三書會通-人物體悟深化.md](../三書會通-人物體悟深化.md) 裡「九人 × 三書 出現地圖」一表；王清任見 [全真龍門基礎丹功講義-导读.md](../全真龍門基礎丹功講義-导读.md) 第五節。

**不收**
- 與修行無關的領域（投資、科技、中醫、科學、西方哲學、內容創作等）。
- 孔子、孟子：原人格庫把它們列在「儒釋道」，但本 repo 沒有任何導讀使用他們，暫不收。

**本次取得他本人四部著作的梵文全文，一手語料 19 KB → 約 1.09 MB，成為本 repo 最大的一手語料。**

**三個最鋒利的結果**：

**① 他從不在自家系統裡提自己學派的名字。** `pratyabhijñā` 在《怛特羅無上》《怛特羅精要》《至上義精要》《覺之十五頌》**全部 0 次**（合計約 58,457 詞）；只有註 Utpaladeva 的書時才用（12.5／萬詞）。
**這與 [Utpaladeva](utpaladeva-perspective/SKILL.md) 是同一個結果的跨代復現**——他創立該學派而自己 450 首讚歌裡該詞 0 次。

**② 他既被註者放大，也是放大者。** Yogarāja 註他最淺那部，`camatkāra` 用得比他密約 49 倍；而他註 Utpaladeva 時把 `pratyabhijñā` 從 0 拉到 12.5／萬詞。**所以「註者把框架讀進文本」不是後人的毛病，是這個註釋傳統的工作方式。本 repo 第三個案例。**

**③ 只有節本需要「四卵」這個鷹架。** `aṇḍacatuṣṭaya` 在 46,378 詞的巨著裡 **0 次**，在《至上義精要》是第 4 頌的總架構。**大書有 37 章可以慢慢走；壓到 105 頌才需要一個四格的盒子裝 36 諦。**

### ⚠️ 而本次重建自己犯的第四個錯，連帶改動了本 repo 一條既有結論

**我原先用「平均詞長」當梵文密度代理，宣稱他的四部作品是一條遞降序列（10.46 → 8.95 → 8.50 → 8.20 → 6.65），據此說「他說他簡化了，而他真的簡化了」。**
**那個宣稱撤回。** 決定性對照：**《怛特羅無上》與《怛特羅精要》的開篇第一頌內容相同**，而

| 同一首頌 | 詞數 | 平均詞長 | 總字母 |
|---|--:|--:|--:|
| 《怛特羅無上》版 | 14 | **14.86** | 208 |
| 《怛特羅精要》版 | 18 | **11.39** | 205 |

一邊寫 `bharitatanuśca`、`hṛdayamanuttarāmṛtakulaṃ`，另一邊寫 `bharitatanuś ca`、`hṛdayam anuttarāmṛtakulaṃ`。
**字母數幾乎相同，而轉寫慣例造成的落差（3.47）大於我要證明的落差（1.96）。**

> ⚠️⚠️ **連帶後果**：[自在認出論釋](../自在認出論釋-Īśvarapratyabhijñāvimarśinī-Abhinavagupta.md) 檔記有「三代『為鈍根者而寫』而簡化在字面上並沒有發生」（依據 9.9／9.1／9.3 對 8.5）——**那些也是跨檔比較，落差同樣在 3.47 的量級內。該結論已改標「未定」（留檔不刪）。**
> **✅ 而三代的文本鏈仍然成立**（`janasyāyatnasiddhyartham` → `mandabuddhīn pratī` → `sukumāramatayaḥ`）——**那是引文，不是測量。**

**✅ 不受轉寫影響、因此仍成立的結構證據**：章數 **37→22**、單位 **5,860→748**（7.8 倍）；論辯標記（`nanu`／`iti cet`／`pūrvapakṣa`）在那部 105 頌本**全部歸零**；節本指回大書 **7 次**；鷹架詞只在節本。
**他的簡化是刪章數、刪論證、加一個總架構的盒子——不是把句子寫短。**

**新增一條查核規則**：**跨檔比較任何「每詞」指標之前，先找一段兩檔都有的相同內容，量它；假影大於訊號就不要用那個指標。**

## 2026-11-04：Bhāskara 入庫——補上本 repo 一個長期的方法論缺口

**本 repo 反覆指認「註釋者把框架讀進一個沒有那套框架的文本」**（見 [Kṣemarāja](ksemaraja-perspective/SKILL.md)、[至上義精要註-Yogarāja](../至上義精要註-Paramārthasāravivṛti-Yogarāja.md)）。
**但只有一家註的時候，兩個解釋分不開**：**(a) 是這個註者自己讀進去的；(b) 那套框架本來就屬於活的傳統，只是根本經文極簡。**
[sun-buer-perspective 的 04 檔](sun-buer-perspective/references/research/04-external-views.md)就寫著這個限制：**「我沒有陳攖寧以外的註本。」**

**《濕婆經》有兩家獨立的註**——**Bhāskara《Vārttika》（75 條，20／10／45）**與 **Kṣemarāja《Vimarśinī》（77 條，22／10／45）**。
**所以這一次分開了。**

### ✅ 結論：(a) 被排除

**十三個克什米爾濕婆派核心術語在 180 詞的《濕婆經》裡 0 次**（svātantrya／vimarśa／prakāśa／spanda／pratyabhijñā／camatkāra／mala／āṇava／māyīya／kārma／turya／anuttara／samāveśa），
**而在兩家互不相干的註裡 13／13 全部都有。**

> **📌 所以本 repo 對「註者放大」的描述要修正一層。**
> **不是「某個註者把他的框架讀進文本」，而是「這個註釋傳統的整套技術語彙在它所註的根本經文裡不存在，而每一家註者各自供應它」。**
> **這是傳統的工作方式，不是個人的毛病。**

⚠️ **不對等須隨結論一起說**：Kṣemarāja 那一側取自他的《[認出之心要](../認出之心要-Pratyabhijñāhṛdaya-Kṣemarāja.md)》＋《[振動抉擇](../振動抉擇-Spandanirṇaya-Kṣemarāja註.md)》（3,077 詞），**不是他的《濕婆經疏》（Vimarśinī）——GRETIL 沒有。** 13／13 的結論不受影響，**但「兩家對同一條經的處理差異」量不出來。**

### ✅ 本 repo 第一次為詞頻宣稱附上顯著性檢定

**經文只有 180 詞，每個術語的期望值只有 0.06–0.73——單項的「0 次」在統計上毫無意義。**
**只有合計 13 個詞（230.0／萬詞 → 期望 4.14、實際 0、Poisson p ≈ 0.016）才構成證據。**
⚠️ **回頭看，本 repo 此前的詞頻宣稱都沒有做這一步。語料短的那些（如孫不二的 896 字）應該補。**

### ⚠️ 而他是本 repo 註者系列裡唯一的反例

| 註者 | 註誰 | 註 vs 本文的平均詞長 |
|---|---|---|
| Yogarāja | Abhinavagupta《至上義精要》 | **11.26 對 8.20（密 37%）** |
| Kṣemarāja | Utpaladeva | 註比頌文密 |
| **Bhāskara** | Vasugupta《濕婆經》 | ⚠️ **9.42 對 9.93（低 5%）** |

**篇幅 17.9 倍（180 → 3,218 詞），而平均詞長反而降。**
✅ 這個比較是**同檔、同輸入者**的，所以可靠（跨檔不可比，見《[怛特羅無上](../怛特羅無上-Tantrāloka-Abhinavagupta.md)》檔的更正節）。

### ✅ 一條舊紀錄現在有了原因

《[濕婆經](../濕婆經-Śivasūtra.md)》檔（2026-10-14）記著兩家分章 20／10／45 對 22／10／45，「**原因是兩家對第一章若干條的斷句不同**」。
**而原因是他自己說的**〔1.1:14〕：
> **praśleṣāśleṣapāṭhābhyāṃ sūtram āha maheśvaraḥ**
> 「大自在天是以『連讀』與『不連讀』兩種讀法說出此經的。」

**所以那兩條之差不是傳抄失誤，是解經原則的直接後果。**
⚠️ **但他宣告了這個原則卻幾乎沒有執行**：`praśleṣa`／`āśleṣa`／`athavā` 各 1 次，757 首裡只有一處真正給了第二種解釋。
